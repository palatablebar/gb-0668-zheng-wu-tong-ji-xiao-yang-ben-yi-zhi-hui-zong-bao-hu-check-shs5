# 数据定义

输入为完整地区×类别矩阵，count为非负人数，0是有效计数，缺失不等于0。0<count<阈值为主抑制；在完整二分图上按最小边际权重寻找替代路径，使每条隐藏边进入环，并以桥边检测核对线性可还原风险。选择过程确定性，使用贪心补环，不宣称全局最优。行列源合计必须与复算一致。发布CSV只包含抑制后的值，结构或保护检查失败时禁止导出。

- 空串、`-`、`N/A`、`NULL`、`未知`是缺失哨兵，不作为零。
- 原始批号、事件号均为文本，保留前导零。
- CSV支持UTF-8 BOM和GB18030，必须有完整表头，支持列顺序调整。
- 文件最大2MB、10000条记录；读取时逐记录校验，计算阶段保留受此上限约束的数据。
- 空文件、全空行、仅表头分别标记EMPTY_FILE、BLANK_ONLY、HEADER_ONLY。
- 多余列隔离；非法引号导致整次请求失败，不保存半批。
- 幂等键=输入字节摘要+规则版本+参数；内容完全相同复用批次。
- 复核采用整数版本比较，旧版本返回409。

计数与代价上限为1000000000000，极值返回字段错误；同一cell_id不得指向不同地区与类别。
